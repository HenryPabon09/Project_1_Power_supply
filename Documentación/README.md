# Project documentation

This directory groups the engineering documentation associated with the Multi-Output Power Supply project.

## Available design artifacts

- [Electrical power tree](Electrical%20power%20tree.drawio) — functional power-distribution diagram.

## Documentation structure

As the design progresses, organize the technical records using the following subjects:

1. **Requirements:** electrical specifications, functional and non-functional requirements, design constraints and traceability.
2. **Architecture:** block diagrams, power tree and interface definitions.
3. **Component selection:** manufacturer datasheets, exact MPNs, design calculations and verification notes.
4. **Circuit design:** schematics, feedback networks, protection and filtering.
5. **PCB design:** stack-up, design rules, copper sizing, thermal considerations and fabrication outputs.
6. **Validation:** test procedures, measurement records, deviations and corrective actions.

Only include released or reviewed documents in the corresponding section. Keep preliminary calculations clearly identified as preliminary, and preserve the revision/date of manufacturer datasheets used for component decisions.
